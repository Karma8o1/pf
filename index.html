A multi-company loan servicing platform ran on SQL Server and SSIS, with chronic resource contention and slow nightly processes. Supervisors also read call transcripts by hand, so scoring lagged days behind the calls.

What I did

  • Led the migration onto Snowflake + dbt and rewrote the slow SQL processes as modelled, tested dbt transformations.
  • Built a call-scoring pipeline in dbt on Snowflake Cortex AI — new transcripts are picked up, scored, and loaded into the analytics model with no manual review.
  • Built a multi-agent reasoning framework with a central skill store: an orchestrator runs specialised agents in parallel, each solves independently, then they vote. Lower hallucination risk than a single-model call.
  • Built a test-data workflow where agents read dbt data contracts and generate synthetic seeds, so nobody waits on production data to test a model.
  • Moved Argo Workflows CI/CD from plaintext credentials to OAuth and stripped hardcoded secrets out of every pipeline config.
  • Added build-failure locking to the single-trunk dbt repo, so a failed deployment can't cascade into staging or prod.
  • Set up Elementary across all models for freshness, volume and schema-drift checks, and wrote 50+ dbt tests across Silver and Gold.

What changed

~20% faster pipeline runs Transcript scoring: days → near real-time ~25% more issues caught before Gold Highest bug resolution rate on the team
